# دليل رفع النسخة على استضافة مجانية

هذا المجلد جاهز للرفع كـ static website.

## محتويات المجلد

- `index.html`
- `test.css`
- `test.js`
- `thresholds_from_pdf.json`
- `firasa_master_dataset.json`
- `models/face_landmarker.task`

## مهم جدا

إذا أردت أن يعمل:

- فتح الكاميرا
- رفع صورة
- تشغيل الصفحة عند العميل بسهولة

فلازم الموقع يكون شغال على:

- `https`

وليس `file://`

## أسهل طريقة مجانية الآن

ارفع هذا المجلد على:

- Netlify

بعد الرفع سيعطيك رابط مجاني مثل:

```text
https://your-project-name.netlify.app
```

وهذا مناسب جدا للتجربة مع العميل.

## خطوات الرفع على Netlify

1. افتح:

```text
https://app.netlify.com/drop
```

2. اسحب مجلد `free_host_package` أو ملف zip الخاص به

3. انتظر حتى يكتمل الرفع

4. سيظهر لك رابط مجاني مباشر

5. أرسل هذا الرابط للعميل

## لو عندك دومين خاص

مثال:

```text
firasa.yourdomain.com
```

يمكنك بعد الرفع ربطه بالموقع من داخل Netlify.

## لو لا يوجد دومين خاص

لا مشكلة.

يمكنك استخدام الرابط المجاني الذي تعطيه Netlify مثل:

```text
https://example-name.netlify.app
```

## ملاحظات مهمة قبل إرسال الرابط للعميل

1. افتح الموقع بنفسك أولاً
2. جرّب الكاميرا
3. جرّب رفع صورة
4. تأكد أن النتائج تظهر
5. تأكد أن المتصفح طلب إذن الكاميرا

## ماذا تقول للعميل

ارسل له:

1. الرابط
2. اطلب منه فتحه من Chrome أو Safari
3. اضغط فتح الكاميرا أو ارفع صورة
4. لو طلب إذن الكاميرا اختر Allow

## لو أردت Domain احترافي أكثر

بعد نجاح التجربة:

- إما تشتري domain
- أو تستخدم subdomain من domain عندك

مثال:

```text
firasa.example.com
```

ثم تربطه بالموقع المجاني.

## بديل مجاني آخر

لو تريد بديل:

- Cloudflare Pages

لكن Netlify أسهل في الرفع السريع لأنك تستطيع الرفع مباشرة بالسحب والإفلات.
