# تَوَافُق (Tawafuq)

منصّة زواج وتوافق تجمع بين **علم الفِراسة** (قياسات بنيوية للوجه فقط) و**التقييم النفسي**.

## بنية المجلد

| المجلد | المحتوى |
|--------|---------|
| `frontend/` | موقع Tawafuq (React/HTML + CSS + JS) — الواجهة الأساسية |
| `cinematic_ui/` | التدفّق الكامل للتطبيق في 13 شاشة (من تسجيل الدخول → التصوير → الأسئلة → التحليل → التوافق) |
| `demo/` | منصّة اختبار قائمة بذاتها (بيانات + موديل + سكور + ماتشينج) — افتح `demo/index.html` |
| `pipeline/` | سكربتات بايثون لبناء البيانات (المراحل 1→3 + `fix_ocr.py` لتنظيف النصوص العربية) |
| `data/` | مخرجات المعالجة النظيفة: `phase1_out` `phase2_out` `phase3_out` `reconcile_out` |
| `source_data/` | البيانات الخام: الداتاسِت الكامل + بيانات الأيام + العتبات |
| `models/` | `face_landmarker.task` (موديل MediaPipe لتحديد معالم الوجه) |
| `docs/` | المواصفات: ملخّص العميل، سكيمة قاعدة البيانات، مواصفة الماتشينج، رحلة المستخدم |
| `test.html` / `start_test_server.bat` | تشغيل سريع لمنصّة الاختبار محليًا |

## الملفات الأساسية للبيانات
- **الصفات البنيوية (15 صفة):** `data/phase2_out/traits_kept.json`
- **بنك الأسئلة:** `data/phase3_out/question_bank.json`
- **أسئلة التوافق (73 سؤال):** `demo/data/matching_questions.json`

## تشغيل منصّة الاختبار
1. شغّل `start_test_server.bat` (أو `demo/start.bat`)
2. افتح المتصفّح على العنوان المحلي

> كل النصوص العربية في ملفات JSON تم تنظيفها من أخطاء الـ OCR. الحقول المسمّاة `raw` تحتفظ بالنص الأصلي عمدًا للمرجعية.
