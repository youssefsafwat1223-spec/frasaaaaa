# دليل التشغيل على Mac

هذا المجلد فيه نسخة جاهزة لتجربة نظام الفراسة بشكل محلي على الماك.

## الملفات الموجودة

- `test.html`
- `test.css`
- `test.js`
- `thresholds_from_pdf.json`
- `firasa_master_dataset.json`
- `models/face_landmarker.task`
- `start_server.command`
- `check_and_run.command`
- `requirements_full_pipeline_mac.txt`
- `install_full_pipeline.command`

## المطلوب قبل التشغيل

لازم يكون عند صديقك:

1. جهاز Mac
2. متصفح مثل Chrome أو Safari
3. إنترنت
4. `python3` موجود على الجهاز

## هل يحتاج تثبيت Packages؟

### لتجربة صفحة HTML فقط

لا.

النسخة الحالية الخاصة بالتجربة تحتاج فقط:

1. `python3`
2. متصفح
3. إنترنت

ولا تحتاج `pip install` لأي package إضافية من أجل فتح الصفحة وتجربة الكاميرا أو رفع صورة.

### لو تريد تشغيل النسخة الكاملة الخاصة بالتحليل Python

هنا يحتاج تثبيت packages إضافية مثل:

- `numpy`
- `opencv-python`
- `mediapipe`
- `pymupdf`
- `pypdf`

## طريقة التشغيل

### الطريقة السهلة من Terminal

1. افتح Terminal
2. ادخل إلى مجلد `mac_test_package`
3. شغل الأمر التالي:

```bash
python3 -m http.server 8000
```

4. افتح هذا الرابط في المتصفح:

```text
http://127.0.0.1:8000/test.html
```

## طريقة ثانية باستخدام الملف الجاهز

1. افتح Terminal داخل نفس المجلد
2. نفذ هذا الأمر مرة واحدة فقط:

```bash
chmod +x start_server.command
```

3. ثم شغل:

```bash
./start_server.command
```

4. بعد ذلك افتح:

```text
http://127.0.0.1:8000/test.html
```

## ملف أسهل للتأكد والتشغيل

يمكن تشغيل هذا الملف:

```bash
./check_and_run.command
```

هذا الملف:

- يتأكد أن `python3` موجود
- ثم يشغل السيرفر مباشرة

## تثبيت packages للنسخة الكاملة

لو صديقك سيجرب فقط صفحة HTML فلا يحتاج هذه الخطوة.

أما إذا كنت تريد منه تجهيز بيئة Python الكاملة، يفعل الآتي:

1. افتح Terminal داخل المجلد
2. نفذ مرة واحدة:

```bash
chmod +x install_full_pipeline.command
```

3. ثم شغل:

```bash
./install_full_pipeline.command
```

هذا سيقوم بتثبيت:

- `numpy`
- `opencv-python`
- `mediapipe`
- `pymupdf`
- `pypdf`

## مهم جدا

- لا تفتح `test.html` مباشرة
- لازم تفتحه من خلال السيرفر المحلي
- لازم يكون الإنترنت شغال لأن MediaPipe يتحمل من الإنترنت
- لو الكاميرا لم تعمل، يمكن تجربة رفع صورة بدل الكاميرا
- لو طلب المتصفح إذن الكاميرا، لازم تعمل `Allow`

## كيف يجرب النظام

يمكنه التجربة بطريقتين:

1. فتح الكاميرا
2. رفع صورة من الجهاز

## أفضل طريقة للتجربة

- صورة واضحة
- وجه واحد فقط
- إضاءة جيدة
- الوجه يكون ظاهر بالكامل

## ماذا نحتاج منه بعد التجربة

نحتاج منه أن يرسل:

1. Screenshot للنتيجة
2. هل الكاميرا اشتغلت أم لا
3. هل رفع الصورة اشتغل أم لا
4. هل ظهرت صفات غلط
5. هل النظام قال يوجد لحية مع أن الشخص بدون لحية

## لو ظهر خطأ

يجرب هذه الخطوات:

1. يقفل الصفحة ويفتحها مرة ثانية
2. يتأكد أن السيرفر شغال
3. يتأكد أن الرابط هو:

```text
http://127.0.0.1:8000/test.html
```

4. يجرب صورة ثانية أو متصفح ثاني

## لو لم يوجد python3 على الجهاز

في هذه الحالة يجب تثبيت Python 3 أولا.

أسهل طريقة:

1. تنزيل Python 3 من الموقع الرسمي:
   [https://www.python.org/downloads/macos/](https://www.python.org/downloads/macos/)
2. تثبيته
3. ثم إعادة تشغيل Terminal
4. ثم تجربة التشغيل مرة ثانية

- تجربة الكاميرا
- تجربة رفع الصور
- مراجعة النتائج
